# Metroman Website

Metroman is an interactive web experience that visualises different regions through a dynamic map interface, paired with curated video content. The project blends geospatial interaction with media playback to create an engaging, exploratory user experience.


---

## Features

- **Interactive Map**
  - Built with Leaflet
  - Clickable regions (provinces / cities)
  - Smooth zooming and navigation

- **Region-Based Video Playback**
  - Each region is linked to a video
  - Modal-based playback experience


- **Language Support**
  - Multi-language UI support
  - Easily extendable for additional languages
  - Designed for global accessibility

- **Light / Dark Mode**
  - Toggle between light and dark themes
  - Improves usability in different environments
  - Consistent styling across components
